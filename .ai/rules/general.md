## Use licensed Metronic for project UI
The user requests Metronic as the UI standard throughout this project and states they own a license. Consult https://preview.keenthemes.com/html/metronic/docs/ for frontend work. Reuse the installed Metronic Bootstrap layouts, components, utilities, icons, and plugin integrations; verify installed versions before applying documentation examples. Prefer existing theme patterns over introducing a different design system.
